# THE ENVIRONMENT LAYER (E) — external parameters, proposed 2026-07-13 (Sina's insight)

The gate weights measured in decibans are NOT constants. They are coupling parameters
conditioned on an epistemic environment E:

    logit P(move) = SUM_i  w_i(E, t) * x_i

The AXIOMS (A0 access, A1 channel, A2 inertia) are the invariants. The WEIGHTS run
with the environment. Two classes of external parameter, entering differently:

## Class T — TECHNOLOGY: moves channel-reliability parameters r_c(t)
r_c = the trustworthiness of evidence channel c (video, photo, document, testimony,
biological). Technology shifts r_c, which RECLASSIFIES evidence across the seam:
- r falls (deepfakes): the channel's truth becomes an expert-credibility contest at
  trial -> evidence MIGRATES documentary -> credibility -> fact-armor over it RISES.
- r rises (DNA): frozen facts become revisable -> new statutory channels open to
  carry the new access -> fact reversals cluster there.
The axioms do not move. The mapping evidence-type -> channel moves.

## Class C — CONSTITUTIONAL/REGIME: rewrites the gates themselves
Legislation/constitutional change can alter A1's forums, A2's presumptions, create or
destroy review channels, or (value skeleton) install/delete heads of damages.
Already-observed parameter jumps in our own register:
- Germany 2017: D_grief channel INSTALLED (Hinterbliebenengeld) — read in full.
- China 2022: rural/urban split DELETED from the death formula — read in full.
- UK 2020: bereavement eligibility widened after human-rights incompatibility.

## RETRODICTIONS (already happened; consistent with the E-layer)
1. Photography/audio arc: skepticism -> "pictures don't lie" era -> forgery era ->
   authentication regimes. A full r-cycle, historically documented.
2. DNA (r_bio UP): post-conviction DNA statutes = A1-type channels legislated to carry
   A0-type new access; decades-old fact findings reopened THROUGH them, not around them.

## PRE-REGISTERED PREDICTIONS — the deepfake shock (r_video DOWN), direction fixed NOW
P1. Authentication disputes over video/audio rise; appellate courts increasingly DEFER
    to trial-level authenticity findings (they rest on live expert credibility).
P2. The documentary-gate weight for video-based fact challenges DECAYS toward the
    credibility floor, measured in decibans, as authentication regimes arrive.
P3. A SPLIT emerges WITHIN video: cryptographically provenanced media (content-
    credential/C2PA-type) retains documentary-grade weight; unprovenanced video falls
    to credibility-grade. The documentary/credibility split reproduces itself one
    level down.
P4. Legislatures/rule-makers respond with gatekeeping (pretrial authentication
    hearings, amended evidence rules) — an A1-type channeling move, not an A0 repeal.

## METHOD — event-study (regime discontinuity)
Pick a documented external event with a date (rule amendment, statute, landmark).
Measure the relevant gate weight (db) in windows BEFORE and AFTER. The event date and
predicted direction must be registered before outcome data is read.

## FALSIFIABILITY GUARD (mandatory)
A parameter change may be invoked ONLY IF: (a) it is a documented external event whose
date is independent of our outcome data, and (b) the direction of its effect was
registered beforehand. Post-hoc "the environment must have changed" is PROHIBITED —
that door stays nailed shut.

## FALSIFIERS
- Deepfake era arrives and video-based fact challenges KEEP documentary-grade success
  (no migration) -> the channel-reliability mechanism is wrong.
- Gate weights drift materially BETWEEN documented shocks (stationarity fails) -> the
  piecewise-stationary model is wrong and the E-layer as designed dies.
